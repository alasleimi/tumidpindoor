\section{Fairness rule: match acquisitions, not feature shape}
This report does \emph{not} impose a delay-only rule. A challenger may use delay, noisy received power, AoA/AoD, complex CIR/CSI, or another physically measurable feature from the same acquisition. Noise is applied coherently: lower SNR perturbs power, delay and angle and increases path dropout. We do not give a method clean power while corrupting only delay.

What is matched is the information and calibration budget. If Majid's protocol gives $N$ survey locations and $Q$ query acquisitions, every challenger gets those same locations and acquisitions. It may not request a dense labelled map, thousands of ungranted simulator examples, unmeasured candidate fingerprints, exact simulator ray/VT identifiers, the true query coordinate, or a clean latent channel. A measurable transmitter channel or physical transmitter identity is allowed.

The original simulator projects, raw data and random seeds are unavailable. Thus our numbers are executable \emph{replacement-scene evidence under a paper-shaped protocol}, not claims to exactly reproduce a published number. Published values are shown only as context and never pooled with reconstructed results.

\section{MPUrge VT and CNN status}
\subsection{Original MPUrge virtual-transmitter mapping}
A reflected path with range $r=c\tau$ and arrival direction $\mathbf u$ proposes a virtual transmitter $\mathbf v=\mathbf x+r\mathbf u$. MPUrge associates proposals across an ordered calibration sequence, retains persistent VTs and purges transient clutter. The corrected code uses total window $P=5$ (half-window two), paper conflict ordering, per-transmitter support and dynamic threshold descent until exhaustion. Unknown cardinality is primary; true cardinality is diagnostic only.

The smoke run exercised all 13 executable branches and all 26 dynamic survival thresholds. Bernoulli/RFS tracking obtained \diag{} VT $F_1=0.9554$, symmetric-Chamfer set error $0.0559\m$, and downstream localisation $0.286\m$. These are branch diagnostics, not a final leaderboard; the full aggregation is audited separately. Exact ray/VT IDs are forbidden. A supervised VT PointNet requiring 5,000 extra labelled simulator examples is excluded because of extra information budget, not because PointNet or multimodal features are forbidden.

\subsection{CNN paper}
The paper-shaped training set has 20 reference points, 60 AP positions and seven obstruction configurations ($8{,}400$ labelled fingerprints per room), at 60 GHz, 2 GHz bandwidth, nominal 20 dB SNR and at most nine paths. The paper reports Room-A RMSE $1.82\m$ classifier/$1.84\m$ regressor versus MCA $2.58$--$2.60\m$; Room-B $2.14/1.47\m$ versus MCA $3.64$--$3.65\m$. These are \paper{} values.

Our corrected design separates a privileged \emph{paper-condition-map} bracket, which is told the true obstruction map, from a deployable \emph{environment-blind} bracket, which pools all maps and selects only from observed noisy fingerprints. Validation maps are now fit-only, and validation queries use independently corrupted repeat acquisitions, preventing identity self-matching. Older smoke values are intentionally not ranked because this correction changes selection; the corrected rerun belongs in the full release.

\section{Four protocols in plain language}
\paragraph{SMART--LEA.} Input is one independently noisy array-CIR per measured survey/query location and transmitter; delay, power and AoA are extracted from it. A sparse reference map is built, locked off-grid positions are test-only, and the output is a receiver coordinate. Report mean, median, RMSE and tail percentiles by spacing/noise. LEA constructs one local candidate per transmitter, ranks them by residual, then combines the best $L$; LEA-4 uses four.

\paragraph{MPUrge.} Input is an ordered sequence of path sets plus known \emph{calibration} receiver poses. Output is a persistent VT set and downstream location. Held-out query positions are never used for association. Score set precision/recall/$F_1$, Chamfer set error, map cardinality and downstream position error.

\paragraph{MPUrge--MAP.} Input is a sparse map of 80 measured reference fingerprints and one noisy query. References and locked off-grid queries are disjoint; learned choices use separate validation seeds/queries. The output is 2-D position and the primary score is paired Euclidean error. Empty/missed/duplicate path cases have fixed finite behavior.

\paragraph{CNN.} Input is a fixed-length tensor of up to nine observed paths for an AP--receiver link. Training uses the paper-shaped $20\times60\times7$ links per room; test uses 1,600 spatially off-grid links. The network outputs either one of 20 reference classes or continuous $(x,y)$. Report RMSE and the complete Euclidean-error distribution, separately for privileged and environment-blind brackets.

\section{Reproducible explanations of the method families}
\paragraph{MCA and corrected MPUrge--MAP.} MCA returns the coordinate of the measured reference with smallest fingerprint distance. MPUrge--MAP keeps the three smallest-score references and computes
\[
 \widehat{\mathbf x}=\frac{\sum_{i\in\mathcal N_3}(s_i+\epsilon)^{-1}\mathbf x_i}
 {\sum_{i\in\mathcal N_3}(s_i+\epsilon)^{-1}}.
\]
The score, tie behavior, padding, empty sets and $\epsilon$ must be frozen before test.

\paragraph{Symmetric Chamfer and subset heads.} For path sets $A,B$,
\[
d_{\rm Ch}=\frac1{2|A|}\sum_{a\in A}\min_{b\in B}\rho(a,b)+
\frac1{2|B|}\sum_{b\in B}\min_{a\in A}\rho(a,b).
\]
The two directions penalize missing and extra paths. Temperature weighting uses $w_i\propto e^{-s_i/T}$ with validation-frozen $T$. Subset consensus forms estimates from multiple top-candidate subsets and chooses the most internally consistent. None improved the corrected MAP baseline here.

\paragraph{Spatial graph and analytic residual.} Connect measured survey positions to spatial neighbors, with Laplacian $L$. Smooth evidence by $(I+\lambda L)\widetilde z=z$. A safer learned version starts from analytic $\mathbf x_0$ and predicts only $\Delta\mathbf x$, so $\widehat{\mathbf x}=\mathbf x_0+\Delta\mathbf x$. Multimodal residual learning ranked third; delay-only graph smoothing oversmoothed scene boundaries.

\paragraph{PointNet/DeepSets.} Embed paths independently and pool:
\[
h=\operatorname{pool}_{j}\phi(p_j),\qquad \widehat{\mathbf x}=g(h).
\]
Max/mean pooling makes $h$ invariant to path order. A direct head predicts coordinates. A candidate reranker combines query/reference embeddings, their difference and the measured reference coordinate, then predicts compatibility. Multimodal direct PointNet was strong; delay-only direct PointNet failed.

\paragraph{Genuine cross-attention.} Query paths form $Q$, candidate-reference paths form $K,V$:
\[
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\left(QK^\top/\sqrt d+M\right)V,
\]
where $M$ masks padding. Pool attended query tokens to one score per \emph{measured} candidate, then softmax scores into coordinate weights. Random path permutations in training and evaluation verify invariance. The $0.3434\m$ result is real attention and does not inspect unmeasured candidates.

\paragraph{Candidate self-attention.} Each measured candidate is a token containing its coordinate, analytic score and query--reference features. A Transformer lets candidates compare before producing weights. No candidate index encoding is supplied, and evaluation permutes candidates. It scored $0.3349\m$.

\paragraph{Beta survival and Bernoulli/RFS.} A path track has survival $\pi\sim\operatorname{Beta}(a,b)$. Detection increments $a$; a credible miss increments $b$. Marginalizing $\pi$ avoids deleting a reflector after one dropout. In the RFS version, every VT also has existence probability $r$, updated from detection, clutter and survival likelihoods; birth/confirmation/deletion are probabilistic. Association uses observable geometry/features, never true ray identity.

\paragraph{DiffAssign-K.} Build an observed-path-to-map cost matrix, add dummy rows/columns for birth/miss, and use Sinkhorn normalization for a soft nearly doubly-stochastic assignment. Choose cardinality $K$ by a frozen BIC-like penalty; true cardinality is never primary.

\paragraph{Assigned-VT consensus.} Every assigned VT/path gives a receiver hypothesis, e.g. $\mathbf x_j=\mathbf v_j-c\tau_j\mathbf u_j$. Robust inverse-residual weights fuse the hypotheses. This analytic use of same-acquisition AoA reached $0.3463\m$.

\paragraph{Coherent ADP and Survival-CIR.} Coherent ADP compares normalized complex angle--delay profiles made directly from noisy array CIRs, then interpolates the nearest measured coordinates. Survival-CIR feeds fixed summaries of CIR coherence, delay, noisy power, angle and track survival into ExtraTrees. Hyperparameters are validation-frozen. Its $0.2601\m$ performance, close to Beta survival, points to survival-aware multimodal representation rather than one special neural architecture.

\paragraph{EvoMDP and RRLE.} EvoMDP combines frozen distances/ranks using coefficients selected only on validation scenes. RRLE is a map-aware mixture of analytic, nearest-neighbor and learned experts whose router sees uncertainty and map-density features. Neither produced a confirmed MAP gain here.

\section{Sequential supplement: causal analytic HMM}
For ordered trajectories, combine the analytic observation likelihood with a causal motion prior:
\[
p(\mathbf x_t\mid\mathbf y_{1:t})\propto p(\mathbf y_t\mid\mathbf x_t)
\sum_{\mathbf x_{t-1}}p(\mathbf x_t\mid\mathbf x_{t-1})p(\mathbf x_{t-1}\mid\mathbf y_{1:t-1}).
\]
The frozen HMM scored $0.3802\m$ versus $0.9654\m$ for framewise analytic MAP: gain $0.5852\m$, 95\% CI $[0.4958,0.6783]\m$, over 270 physical frames/1,350 condition rows. It uses neither future measurements nor query truth. It applies only when temporal ordering is available, so it is not smuggled into static leaderboards.

\section{Multi-level/irregular maps: causal positive findings}
The selection policy sees 72 possible sites but a site's fingerprint is hidden until it buys that measurement. Thirty-six protected query fingerprints/coordinates never enter selection. Policies use nested acquisition paths and budgets 12, 20 and 30; the audit found zero reads of unselected survey features.

At budget 12, geometry-first farthest sampling plus finite-element interpolation was best: $1.5251\m$; no adaptive policy improved it. At budget 20, causal FEM-variation selection plus polynomial/RBF localisation gave $1.4745\m$ versus farthest $1.5463\m$, a point gain $0.0718\m$ with group-bootstrap CI $[-0.1534,0.3035]\m$. At budget 30, causal GP-variance plus polynomial/RBF gave $1.3434\m$ versus $1.4271\m$, point gain $0.0837\m$, CI $[-0.1002,0.2674]\m$. The latter two are promising point estimates, not statistically confirmed wins.

The practical policy is: first acquire geometric coverage; only after enough measured sites support a stable field model, place later fingerprints at high causal interpolation variation/posterior variance. The earlier $1.5935\m$ ``goal-surplus'' claim is retracted because it inspected fingerprints at unmeasured candidate sites. Measuring a dense map and later discarding points is also not calibration saving.

\section{Top three defensible ideas}
\begin{enumerate}
\item \textbf{Survival-aware multimodal fingerprints:} Beta survival and Survival-CIR reduce reconstructed MAP error from $1.0638\m$ to $0.2528$--$0.2601\m$, with paired intervals far from zero.
\item \textbf{Physics anchor plus learned correction:} the multimodal residual graph reaches $0.2745\m$, learning a bounded correction instead of unconstrained coordinates.
\item \textbf{Permutation-invariant candidate reasoning:} self/cross-attention reaches $0.3349/0.3434\m$ using only measured candidates and survives order-invariance tests.
\end{enumerate}
